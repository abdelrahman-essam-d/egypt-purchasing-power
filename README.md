# Egypt Purchasing Power Tracker

Give it a salary and a month, and it tells you what that salary is worth today in Egyptian pounds (adjusted for inflation) and in US dollars.

> Status: work in progress.

## Questions

1. Did the private-sector minimum wage gain or lose purchasing power from January 2022 until today, in real EGP and in USD?
2. After each currency float, how many months did the minimum wage take to get back to its pre-float level, in real EGP and in USD?
3. Does any forecasting model beat a naive baseline when predicting the USD/EGP exchange rate?

Real = adjusted for inflation.

## Done when

- The three questions above are answered with numbers and charts.
- Anyone can run the project by following the steps in this README.
- The tests pass and the data quality checks are written down.
- Every data source is listed with its link and download date.
- The limitations are written clearly.
- The live demo app link works.
